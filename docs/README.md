# The AI Compass

A bilingual local web portal for the Digilians capstone project **Data-Driven Analysis of Global AI Compute Dependency and Arab AI Opportunities**.

The repository includes:

- A responsive English/Arabic project website.
- The six-page Power BI dashboard.
- Full project documentation.
- The capstone defense presentation and final poster.

## Open the website

Open `index.html` directly in a browser. The page is self-contained and does not require external packages or internet-hosted assets.

## Project scope

The analytical solution covers 3,577+ AI system records from 1957 to 2026, a star-schema semantic model, 38 DAX measures, and decision views for market concentration, openness, scale, and Arab and Egyptian readiness.
